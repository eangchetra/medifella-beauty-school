# Medi Fella Beauty School Website

This is a free, static website starter.

Files:
- index.html — website content
- style.css — design
- logo.jpeg — uploaded school logo

To publish free:
1. Create a GitHub account.
2. Create a new public repository, e.g. `medi-fella-website`.
3. Upload all three files.
4. In Settings → Pages, choose Deploy from branch → main → /root.
5. GitHub will give you a free `github.io` website address.

Replace the course text, contact details, social links, and gallery placeholders with your official information.
